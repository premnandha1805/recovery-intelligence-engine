## Brand & Style

The design system projects mission-critical precision, programmatic certainty, and sovereign control over complex enterprise revenue recovery pipelines. It targets principal engineers, VP-level risk officers, and quantitative operations teams who evaluate automated financial infrastructure through the lens of algorithmic explainability, auditability, and deterministic safety guarantees.

The design movement combines **high-density data architecture**, **refined glassmorphism**, and **technical minimalism**. Visual noise is eliminated to give way to high-contrast telemetry, monospace state indicators, and subtle translucent layers that establish optical depth without compromising throughput or clarity.

Key principles:
- **Telemetry First**: Every interface surface prioritizes real-time metrics, causal attribution, and state verification over decorative elements.
- **Calibrated Restraint**: Vibrant accents represent mathematical certainty, uplift, warning thresholds, and algorithmic intervention—never arbitrary ornamentation.
- **Architectural Rigor**: Crisp 1-pixel borders, structural grid alignments, and modular glass panes mimic mission-control avionics and professional-grade developer workbenches.

## Colors

The palette leverages a deep charcoal/slate substrate paired with function-specific spectral signals to convey pipeline health, model confidence, and operational states across high-density analytics surfaces.

### Surface Architecture
- **Base Canvas (`#0B0F17`)**: The foundational void; absolute background layer for full-screen dashboards.
- **Layer 1 Surface (`#111827`)**: Primary card canvas, control panels, and structural sidebars.
- **Layer 2 Elevated Surface (`#1E293B`)**: Hover states, flyout menus, and active interactive regions.
- **Structural Borders (`#1F2937` to `#374151`)**: 1-pixel boundary delineations maintaining crisp contrast between stacked layers.

### Signal Spectrum
- **Primary Emerald (`#10B981`, hover `#059669`)**: Causal recovery confirmed, high recovery probability, compliant execution, and net-positive settlement states.
- **Secondary Cyan (`#06B6D4`, highlight `#38BDF8`)**: Autonomous model reasoning, uplift attribution, dynamic routing nodes, and active machine inference.
- **Warning Amber (`#F59E0B`, deep `#D97706`)**: Anomaly detection, circuit-breaker warning, fallback heuristics engaged, and non-blocking model drift.
- **Critical Crimson (`#F43F5E`, core `#E11D48`)**: Hard guardrail violation, automated intervention killswitch, settlement failure, and security boundary alert.

### Text & Telemetry Contrast
- **Text Primary (`#F9FAFB`)**: High-contrast labels, critical metric counts, and active header states.
- **Text Muted (`#9CA3AF`)**: Contextual metadata, system timestamps, and secondary table columns.
- **Text Dim (`#6B7280`)**: Inactive controls, static column keys, and table borders.

## Typography

Typography establishes an explicit operational divide between natural language context and algorithmic telemetry. 

- **Inter** handles narrative copy, modal descriptions, administrative controls, and system hierarchy. Its neutral, engineered curves guarantee frictionless readability across data-dense views.
- **JetBrains Mono** is mandatory for all quantitative readouts, transaction hashes, confidence percentiles, model weights, status badges, and chronological log traces. Monospaced tabular figures prevent horizontal jitter during live telemetry polling.
- **Scale Hierarchy**: Headlines maintain tight negative letter-spacing for a compact, authoritative editorial tone. All metric labels deploy uppercase styling with expanded tracking to provide immediate legibility in high-stress operational conditions.

## Layout & Spacing

The layout is built around a dense, 12-column adaptive CSS grid optimized for continuous multi-stream data ingestion and multi-monitor operations desks.

### Grid & Density Rules
- **Desktop (1440px+)**: 12 columns, fixed 24px outer margins, 16px to 24px gutters. Workspaces favor 3- and 4-column module splits for side-by-side transaction log review and telemetry inspection.
- **Laptop / Dense Displays (1024px - 1439px)**: 12 columns with 16px gutters, auto-collapsing secondary metrics panels into horizontal sliding drawers.
- **Tablet & Mobile (&lt;1023px)**: 4 to 6 columns. Real-time stream view defaults to single-column stacked telemetry cards with sticky system status banners.

### Spacing Rhythm
Spacing units follow a strict 4px/8px micro-grid. Internal component padding favors dense configurations (`0.875rem` / 14px and `1.25rem` / 20px) to maximize the visible information envelope above the viewport fold. Whitespace is strictly utilized to separate distinct decision domains rather than to create arbitrary emptiness.

## Elevation & Depth

Visual hierarchy is achieved through **low-opacity glassmorphism**, **stacked background tones**, and **inner luminescence borders** rather than diffuse drop shadows.

### Elevation Architecture
1. **Canvas Level (0dp)**: Pure dark substrate (`#0B0F17`) acting as the structural foundation.
2. **Base Glass Panels (1dp)**: `rgba(17, 24, 39, 0.75)` backdrop fill paired with `backdrop-filter: blur(12px)`. Enclosed by a crisp, uniform `1px solid rgba(255, 255, 255, 0.08)`.
3. **Interactive & Active Containers (2dp)**: `rgba(30, 41, 59, 0.85)` fill with `backdrop-filter: blur(16px)` and a dynamic border `1px solid rgba(255, 255, 255, 0.15)`. Used for flyouts, selected table records, and drilldown inspector drawers.
4. **Floating Overlays & Modals (3dp)**: Solid base (`#111827`) coupled with a directional 1px perimeter glow matching the context:
   - AI Reasoning modals: `0 0 24px -4px rgba(6, 182, 212, 0.25), 0 12px 32px -4px rgba(0, 0, 0, 0.8)`
   - Guardrail Violations: `0 0 24px -4px rgba(244, 63, 94, 0.3), 0 12px 32px -4px rgba(0, 0, 0, 0.8)`
   - General Overlays: `0 20px 40px -8px rgba(0, 0, 0, 0.9), 0 0 0 1px rgba(255, 255, 255, 0.1)`

### Boundary Illumination
Cards never use soft ambient drop shadows that bleed into adjacent modules. Every division must be defined by structural 1px hairpins (`#1F2937` or semi-transparent RGBA equivalents), creating a distinct chassis appearance.

## Shapes

The design system employs a **Soft (Level 1)** geometric geometry. Sharp, architectural edges dominate to convey engineering discipline and industrial robustness, softened just enough to mitigate visual fatigue across high-density interfaces.

- **Base Radius (0.25rem / 4px)**: Applied to micro-components including badges, checkboxes, status chips, table action cells, and segmented controls.
- **Card & Modal Radius (`rounded-lg` / 0.5rem / 8px)**: Standard boundary radius for all analytical cards, charts, glass panels, and modal containers.
- **Full Radius (9999px)**: Reserved exclusively for operational status pills (e.g., live pipeline status, model inference indicator lights).

## Components

### Buttons & Action Controls
- **Primary Execution Button**: Emerald solid (`#10B981`) background, deep black text (`#041D14`), semi-bold. On hover, transitions to `#059669` with a localized inset ring `inset 0 1px 0 rgba(255,255,255,0.3)`.
- **AI Action / Causal Trigger**: Cyan solid (`#06B6D4`) with `#082F38` text. Employs a subtle `0 0 16px rgba(6, 182, 212, 0.35)` glow when dynamic optimization mode is active.
- **Ghost / Neutral Action**: Transparent surface, `1px solid rgba(255, 255, 255, 0.12)`, text `#E5E7EB`. Hover transforms to background `rgba(255, 255, 255, 0.05)` and border `#4B5563`.
- **Critical Killswitch / Override**: Crimson border (`#F43F5E`) with `rgba(244, 63, 94, 0.1)` background fill, transitions on hover to solid `#E11D48` with white text.

### Telemetry Badges & Decision Chips
- **Format**: Monospace text (`JetBrains Mono`, 10px / 12px), `padding: 2px 8px`, border radius `9999px` (pill) or `4px` (structural tag).
- **Safe Recovery**: Emerald background `rgba(16, 185, 129, 0.12)`, text `#34D399`, border `1px solid rgba(16, 185, 129, 0.3)`. Features an active pulsing indicator dot for real-time recovery events.
- **AI Dynamic Uplift**: Cyan background `rgba(6, 182, 212, 0.12)`, text `#38BDF8`, border `1px solid rgba(6, 182, 212, 0.3)`.
- **Fallback / Caution**: Amber background `rgba(245, 158, 11, 0.12)`, text `#FBBF24`, border `1px solid rgba(245, 158, 11, 0.3)`.
- **Guardrail Override**: Crimson background `rgba(244, 63, 94, 0.12)`, text `#FB7185`, border `1px solid rgba(244, 63, 94, 0.3)`.

### Form Inputs & Parameter Toggles
- **Input Fields**: Background `#0F172A`, border `1px solid #1F2937`, text `#F9FAFB`. Focus ring shifts to `1px solid #06B6D4` with `box-shadow: 0 0 0 2px rgba(6, 182, 212, 0.2)`. Internal labels use uppercase `label-caps` in JetBrains Mono.
- **Checkboxes & Radios**: 14px squared containers (`roundedness: 4px`), background `#1E293B`, border `1px solid #374151`. Checked state fills with `#10B981` with an SVG sharp checkmark.

### Telemetry Cards & Metric Panels
- **Container Structure**: Translucent panel (`rgba(17, 24, 39, 0.8)`), backdrop blur `12px`, perimeter border `1px solid rgba(255, 255, 255, 0.07)`.
- **Metric Organization**: Top row displays category label (`label-caps`, `#9CA3AF`) and contextual variance pill (`+14.2% uplift`). Core value rendered in `mono-metric-lg` (`#F9FAFB`). Bottom area reserves space for micro-sparklines or confidence distribution bars.

### Data Tables & Event Logs
- **Row Anatomy**: Row height fixed to a compact 36px or 44px. Alternating row fills are avoided; separation is maintained via `1px solid rgba(255, 255, 255, 0.04)`.
- **Hover State**: Highlights row background with `rgba(255, 255, 255, 0.03)` and displays quick-action terminal triggers in the trailing cell.
- **Column Alignments**: Natural language left-aligned (`Inter`); numeric calculations, latency times, timestamps, and currency values right-aligned (`JetBrains Mono`).

### Decision Governance Tree Nodes
- Dedicated structural component depicting automated causal branches. Nodes connect via `1px solid #374151` path lines. Active reasoning branches glow with a subtle `#06B6D4` gradient trail terminating at an intervention resolution chip.
